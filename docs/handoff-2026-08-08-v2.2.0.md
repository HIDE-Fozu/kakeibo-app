## v2.2.0 の内容

### 1. つきいちタスク合体（routine-reminder v1 を移植）
- **schema v6→v7**: `chore_tasks` / `chore_records`（日付は CivilDateConverter・FKカスケード）。
- domain: `chore_schedule.dart` 純関数（次回期日=最後にやった日+間隔・buildChoreStatuses/
  choreMonthMarks/buildChorePlans[文言レス]/choreOverdueCount）。**DateOnlyは移植せず
  CivilDate に addDays/differenceInDays/isBefore/isAfter を追加して統一**。
- `ChoreActions`（features/chores/application）: 全ミューテーション→resync（通知全再予約+
  バッジ）。**resyncはFuture読み（`watch().first`はfake asyncでハングする既知の罠）**。
  通知文言はresync時点のロケールで組み立て（ロケール変更でhome_shellが再予約）。
- 通知/バッジ: `data/notifications/`（flutter_local_notifications 22.x named-params API・
  zonedSchedule・上限60件・許可要求は初回記録後の一度だけ）。**providerはNoop既定**
  （throw既定にするとhome_shell起動時resyncで全widgetテストが死ぬ）。bootstrapがiOSのみ
  実物へ差し替え+tz初期化（失敗時UTC続行）。AppDelegateに UNUserNotificationCenter
  delegate 1行（フォアグラウンドバナー用）。
- 新パッケージ: flutter_local_notifications ^22 / timezone ^0.11 / flutter_timezone ^5.1 /
  app_badge_plus ^1.3 / app_settings ^7。

### 2. 「毎月」タブ（4タブ化・管理ハブ）
- `features/monthly/presentation/monthly_hub_screen.dart`。ボトムナビ=カレンダー・毎月・
  サマリ・設定（`_navToShell=[0,4,2,3]`・入力(1)は従来どおりタブ外）。
- 構成: 今月のこれから（家事期日+固定費予定+見込み収支行）→ 固定費・収入

### 3. 統合カレンダー（ゴースト・家事ドット・見込み収支）
- **ゴースト述語**（recurring_schedule.dart `upcomingOccurrencesInMonth`）:
  `isActive && startYm<=ym && (endYm null || ym<=endYm) && ym > (lastGeneratedYm ?? 0)
  && dueDateIn >= today`。**重複排除は watermark のみ**（実取引と突き合わせない）。
  `>= today` が重要: `>` だと日付変更〜resumeの間に当日分が消える。
- **見込み収支** `monthForecast`: 実績差引+基準日までの予定。基準日=設定
  `forecastAnchorDay`（0=月末・1..31）。過去月=非表示。**当月で基準日超過は月末へ
  フォールバック**。ヘッダー3行目（forecast-line）タップ→基準日シート。
- `_dayCell`: 数字→家事ドット（やった=緑43A047/期日=橙FB8C00/超過=赤kExpense・
  keyつき `chore-dot-*-<iso>`）→実績額→予定額グレー（`ghost-amount-<iso>`）。
  **rowHeight 58→62**。凡例は該当月のみ表示。
- 日パネル: 予定行（`ghost-<ruleId>`・タップでルール編集）+ 家事行
  （chore_day_section: 記録✓・期日行・今日のみ超過行+やったボタン）。
