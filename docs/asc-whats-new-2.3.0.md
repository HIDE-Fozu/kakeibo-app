# ASC「このバージョンの新機能」— 2.3.0（カレンダー刷新・ごみ箱・分割払い拡張）

バージョンページの「このバージョンの新機能」欄に貼る（各4000文字以内）。
書式は docs/asc-whats-new-2.1.0.md に合わせた。
※ 2.2.0(46) を取り下げて 2.3.0 で置き換える場合は、2.2.0 の新機能
（見込み収支・内訳入力の改善ほか 8/16 提出分）をこの文面に統合すること。

### ja

```
Ver 2.3.0
・カレンダー画面のデザインを一新しました。紙の帳簿をイメージした背景と日付ごとのカードで、収入（＋）と支出（−）がひと目で分かります
・画面上部の合計は「今日までの実績」を表示するようになりました。分割払いなど日付が先の支出は、下段の「見込み（月末）」に含めて表示します
・ごみ箱を追加しました。削除した記録は30日間保管され、設定 → ごみ箱 からいつでも元に戻せます
・分割払いの回数を最大420回まで指定できるようになりました
```

### en

```
Version 2.3.0
• Redesigned calendar: a paper-ledger look with a card for each day, showing income (+) and expenses (−) at a glance
• The totals at the top now show actuals up to today. Future-dated expenses such as installments are included in the month-end forecast below instead
• New: Trash. Deleted entries are kept for 30 days and can be restored anytime from Settings → Trash
• Installment plans now support up to 420 payments
```

### zh-Hans

```
2.3.0 版本
• 日历页面全新设计：仿纸质账本的背景与逐日卡片，收入（+）与支出（−）一目了然
• 顶部合计现在显示「截至今天」的实际收支；分期付款等未来日期的支出改为计入下方的「月末预估」
• 新增回收站：删除的记录保留30天，可随时在「设置 → 回收站」中恢复
• 分期付款期数最多可设为420期
```

### ko

```
버전 2.3.0

```
