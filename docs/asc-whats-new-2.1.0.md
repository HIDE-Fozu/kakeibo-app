# ASC「このバージョンの新機能」— 2.1.0（毎月の固定費・収入）

バージョンページの「このバージョンの新機能」欄に貼る（各4000文字以内）。
文字数は len() 実測。書式は docs/asc-store-listings-2.0.0.md §10 に合わせた。

### ja

```
Ver 2.1.0
・「毎月の固定費・収入」を追加しました。家賃・サブスク・給料などを一度登録すると、毎月自動で記録されます
・設定 → 毎月の固定費・収入 から登録できます（金額・カテゴリ・毎月の日付・開始月）
・31日など存在しない日を指定した月は、月末の日付で記録されます
・一時停止や終了もいつでもできます。自動記録された取引は普通の取引と同じように編集・削除できます
```

### en

```
Version 2.1.0
• New: Recurring transactions. Register rent, subscriptions or your salary once and they are recorded automatically every month
• Set them up in Settings → Recurring transactions (amount, category, day of month, start month)
• If a month is shorter than the chosen day, the entry falls on the last day of that month
• Pause or delete rules anytime — auto-recorded entries can be edited like any other transaction
```
