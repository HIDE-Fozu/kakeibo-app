## このセッションで入れたもの（3件・すべてコミット済み）

### 1. 分割払いカードをバックアップに同梱（17329ae・バックアップ形式v9）

- 課題: カード（名称＋実質年率）は SharedPreferences 住まいで、バックアップ
  対象から漏れていた。復元しても金利プリセットが戻らなかった。
- モデルとprefs直列化を `lib/data/settings/installment_cards.dart` に集約し、
  設定画面（AppSettings）とバックアップが同じ形式を読み書きする。
- **形式v9の規約（重要）**: 追加した prefs 由来のキーは
  **「キー欠落＝未収録(null)」＝復元時に端末側を変更しない**。
  空リスト・空文字・既定値（収録済み）とは区別する。v8→v9 の
  マイグレーションでは**補完しない**（補完すると復元で端末の設定が消える）。
- `BackupService` に `prefs` を注入。復元は**DBトランザクション成立後**に
  prefs を置換し、`appSettingsProvider` を invalidate して即反映。

### 2. 買い物メモ（ec2e1bb）

- 日別カードに3つ目のタブ「メモ」。家計簿の入力とは無関係の自由テキスト。
- タブ内は**表示専用**、タップで**全画面の編集ページ**。
  （カレンダー画面は固定レイアウトで、この画面上でキーボードを開くと縦に
  溢れる。ボトムシートでも背後がレイアウトされるためダメで、不透過ルートに
  逃がすのが正解だった。）
- 保険として CalendarScreen に**最低高640のスクロールガード**を追加。
  通常時（iPhone縦持ち）は挙動不変。
- タブ行は3タブとも Flexible（**flex 4:3:2**）。均等flexだと幅が余っていても
  短いタブから切れ、実寸置きにするとドイツ語等の冗長ロケールで溢れる。
  この重み付けが日本語フル表示と localization_test 両立の解。
- 保存先 prefs `shoppingMemo`。バックアップv9に収録。

### 3. 毎月の予算（e769c63）

- **毎月共通の1金額**（ユーザー決定。月ごとの別金額ではない）。
  設定にトグル `budget-switch` ＋ 金額タイル（オンのときだけ表示）。
- 表示は**カレンダー上部サマリに「予算の残り」行**（ユーザー決定）。
  **残り = 予算 − 同じカードの「支出」**。同一カード上の数字で引き算が
  成立するので、ユーザーが画面を見て検算できる（支出の定義は上の列と同じ
  ＝当月は today 打ち切りの実績）。
- 残高なので**＋符号は付けない**（＋は差引・見込みの符号表示だけ。
  FB 2026-08-21「差し引き0なのに+」と同じ考え方）。
- prefs `budgetEnabled` / `monthlyBudgetMinor`（最小単位）。v9に収録。
- 金額ダイアログの TextEditingController は**ダイアログ自身が保持**する。
  呼び出し側で dispose すると閉じるアニメーション中に使われて落ちる
  （実際に踏んだ。`_ExportPassphraseDialog` と同じ形が正解）。
